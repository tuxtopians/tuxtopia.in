# Tuxtopia — ERP Implementation & Customization Solutions

Modern, responsive, GitHub Pages-ready website for **Tuxtopia** (`ERP Implementation & Customization Solutions`).

## Highlights

- **Unified Tuxtopia ERP Suite (9 Core Modules):**
  1. Financial Accounting & Multi-Book Ledgers
  2. Inventory & Multi-Warehouse Management
  3. Manufacturing, Multi-Level BOM & Work Orders (MRP)
  4. Sales & Omnichannel CRM
  5. Procurement & Self-Service Supplier Portal
  6. Human Resources, Shift Operations & Global Payroll
  7. Projects, Timesheets & Milestone Billing
  8. Omnichannel Retail & Offline-First Cloud POS
  9. Custom ERP Workflows, Doctypes & API Integrations
- **Interactive ERP Workbench:** Real-time module switcher showcasing live vouchers, KPIs, document state machines, and operational telemetry across all 9 departments.
- **Tuxtopia Engineering Services:** End-to-End Implementation, Custom Module & Workflow Development, Precision Data Migration, Third-Party Integrations, Training, and 24/7 Managed Support.
- **GitHub Pages Ready:** Includes `.nojekyll` and `.github/workflows/deploy-pages.yml` for automatic deployment on push to `main`.
